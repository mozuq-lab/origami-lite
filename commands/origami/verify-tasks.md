# verify-tasks

## 目的

`/origami:plan-tasks` で生成されたタスク一覧の完了状況を確認し、進捗レポートを表示します。各タスクのチェックボックス状態を集計し、完了率や未完了タスクの一覧を提供することで、テストドキュメント生成の進捗を可視化します。

**引数で仕様書ディレクトリを指定**することで、特定の仕様書の進捗のみを確認できます。

## 事前準備

1. **追加ルールの読み込み**
   - `docs/rule` ディレクトリが存在する場合は読み込み
   - `docs/rule/origami` ディレクトリが存在する場合は読み込み
   - 各ディレクトリ内のすべてのファイルを読み込み、追加ルールとして適用

2. **ディレクトリパスの解決** 🔵
   - 引数で指定されたパスからディレクトリを特定
   - フルパス指定時（`docs/origami/xxx/`）はそのまま使用
   - 仕様書名のみ指定時（`xxx`）は `docs/origami/{spec-name}/` に展開
   - パス末尾の `/` は自動補完

3. **タスクファイルの確認** 🔵
   - `{出力先}/tasks/task-list.md` が存在することを確認
   - 存在しない場合はエラーメッセージを表示し、`/origami:plan-tasks` の実行を案内

## 入力

| 引数 | 説明 | 必須 | 例 |
|------|------|------|-----|
| ディレクトリ | 仕様書ディレクトリパスまたは仕様書名 | ○ | `docs/origami/ecommerce-spec/` または `ecommerce-spec` |

### 使用例

```bash
# フルパス指定
/origami:verify-tasks docs/origami/ecommerce-spec/

# 仕様書名のみ指定（自動展開）
/origami:verify-tasks ecommerce-spec
```

### ディレクトリ解決ルール 🔵

| 入力形式 | 解決後のパス |
|---------|-------------|
| `ecommerce-spec` | `docs/origami/ecommerce-spec/` |
| `docs/origami/ecommerce-spec` | `docs/origami/ecommerce-spec/` |
| `docs/origami/ecommerce-spec/` | `docs/origami/ecommerce-spec/` |

## 実行内容

### 1. 引数解析とディレクトリ解決 🔵

- 引数で指定されたパスを解析
- 仕様書名のみの場合は `docs/origami/{spec-name}/` に展開
- パス末尾に `/` がない場合は追加
- 解決後のディレクトリパスを保持

**解決アルゴリズム**:
1. 引数が `docs/` で始まる場合 → フルパスとして扱う
2. 引数が `docs/` で始まらない場合 → `docs/origami/{引数}/` に展開
3. パス末尾の `/` を統一

### 2. タスク一覧読み込み 🔵

- `{解決後のディレクトリ}/tasks/task-list.md` を読み込み
- ファイルが存在しない場合はエラーを表示して処理中断
- タスク情報を解析

### 3. 完了状態集計

- 各タスクのチェックボックス（`- [x]` / `- [ ]`）の状態を確認
- 完了タスク数と未完了タスク数をカウント
- 各タスクの対象機能と状態を記録

### 4. 進捗計算

- 完了率を計算: `(完了タスク数 / 総タスク数) × 100`
- 進捗バーを生成（視覚的な進捗表示）
- 残り作業量を推定

### 5. レポート生成

進捗状況をサマリー形式で表示：
- 対象ディレクトリ
- 総タスク数
- 完了タスク数
- 完了率（%）
- 未完了タスク一覧
- 次に実行すべきタスクの提案

## エラーハンドリング

| エラーケース | メッセージ |
|------------|----------|
| 引数未指定 | 「仕様書ディレクトリを指定してください。例: `/origami:verify-tasks ecommerce-spec`」 🔵 |
| ディレクトリ未存在 | 「指定されたディレクトリが見つかりません: {パス}」+ 利用可能ディレクトリ一覧 🟡 |
| タスクファイル未存在 | 「タスク一覧ファイルが見つかりません: {パス}/tasks/task-list.md。先に `/origami:plan-tasks` を実行してください」 |
| タスクファイル空 | 「タスク一覧ファイルが空です。`/origami:plan-tasks` でタスクを生成してください」 |
| タスクが見つからない | 「タスク一覧ファイルにタスクが見つかりません。ファイル形式を確認してください」 |
| ファイル読み込みエラー | 「タスク一覧ファイルの読み込みに失敗しました: {エラー詳細}」 |

  /origami:verify-tasks ecommerce-spec
  /origami:verify-tasks docs/origami/auth-system/

## 出力ファイル確認

進捗レポート表示時に、指定されたディレクトリ内の出力ファイルの存在も確認します：

| ファイル | 確認内容 |
|----------|----------|
| `{出力先}/01_機能一覧.md` | 存在チェック |
| `{出力先}/02_動作仕様一覧.md` | 存在チェック |
| `{出力先}/03_境界値分析表.md` | 存在チェック |
| `{出力先}/04_テストケース一覧.md` | 存在チェック |

出力ファイルが存在する場合は、各ファイル内の機能数も表示します。

## 実行後の確認

- 進捗レポートが表示されたことを確認
- 未完了タスクがある場合は次に実行すべきタスクを案内
- 全タスク完了の場合は生成されたドキュメントの一覧を表示
- 🔴項目がある場合は警告を表示

## 関連コマンド

| コマンド | 説明 |
|---------|------|
| `/origami:plan-tasks` | タスク分割計画を生成（verify-tasksの前に実行、出力先ディレクトリを作成） |
| `/origami:run-task` | 個別タスクを実行（task-list.mdから出力先を参照） |
| `/origami:extract-features` | 機能一覧を抽出（--output引数で出力先指定可能） |
| `/origami:behavior-checklist` | 動作仕様一覧を作成（--output引数で出力先指定可能） |
| `/origami:boundary-analysis` | 境界値分析表を作成（--output引数で出力先指定可能） |
| `/origami:generate-cases` | テストケースを生成（--output引数で出力先指定可能） |
