# plan-tasks

## 目的

大規模な仕様書を処理する際のコンテキスト肥大化を防ぐため、仕様書から機能を抽出し、機能単位（F-001, F-002等）でタスクに分割します。生成されたタスクファイルにより、`/origami:run-task` で順次実行できます。

## 事前準備

1. **追加ルールの読み込み**
   - `docs/rule` ディレクトリが存在する場合は読み込み
   - `docs/rule/origami` ディレクトリが存在する場合は読み込み
   - 各ディレクトリ内のすべてのファイルを読み込み、追加ルールとして適用

2. **既存出力の確認**
   - `docs/origami/01_機能一覧.md` が存在する場合は読み込み
   - 既存の機能一覧がある場合は、それを基にタスクを分割

## 入力

以下の形式を受け付けます：

| 形式 | 説明 | 例 |
|------|------|-----|
| Markdown | .md拡張子のファイル | `/origami:plan-tasks docs/requirements.md` |
| テキスト | .txt拡張子のファイル | `/origami:plan-tasks spec.txt` |
| URL | Web上のページ | `/origami:plan-tasks https://example.com/api-spec` |

## 実行内容

**【信頼性レベル指示】**:
各項目について、入力仕様書との照合状況を以下の信号でコメントしてください：

- 🟢 **青信号**: 入力仕様書に明示的な記載がある
- 🟡 **黄信号**: テスト技法・業界標準・Web常識から推測
- 🔴 **赤信号**: 推測の根拠が薄い

### 1. 入力解析

- 指定されたファイルまたはURLの内容を取得
- 入力形式が不正な場合はエラーメッセージを表示
- 既存の `01_機能一覧.md` がある場合は優先的に使用

### 2. 機能抽出

- 「〜できる」「〜する」等の動詞を含む記述を機能として抽出
- 具体的なエンドポイント・画面名の記載を機能として抽出
- URL入力の場合、画面要素から機能を推測
- 各機能に F-XXX 形式のIDを付与（F-001, F-002, ...）

### 3. 依存関係分析

- 機能間の依存関係を特定
- 例：ログイン機能は登録機能に依存しない、プロフィール編集はログインに依存
- 依存関係がある場合はタスクに記載

### 4. タスク生成

- 各機能に TASK-XXX 形式のIDを付与
- タスク番号は入力順に連番で付与（TASK-001, TASK-002, ...）
- 各タスクに処理対象の機能を紐付け
- 依存タスクがある場合は明記

### 5. タスクファイル出力

- `docs/origami/tasks/task-list.md` にタスク一覧を出力
- チェックボックス形式で進捗管理可能な形式

## 信号機判定基準

| 信号 | 判定条件 | 例 |
|------|---------|-----|
| 🟢 青信号 | 入力に「〜できる」「〜する」等の明示的記述がある | 「ユーザーは新規登録できる」 |
| 🟢 青信号 | 具体的なエンドポイント・画面名の記載がある | 「POST /api/users」 |
| 🟡 黄信号 | 記載された機能から一般的に必要と類推される | ログインがあればログアウトも必要 |
| 🔴 赤信号 | 「検討中」「予定」等の不明確な表現がある | 「将来的に実装予定」 |
| 🔴 赤信号 | URL解析で推測の根拠が薄い | 画面要素のみから推測 |

出力先: `docs/origami/tasks/task-list.md`

## エラーハンドリング

| エラーケース | 対応 |
|------------|------|
| 入力ファイルが見つからない | エラー: 「ファイルが見つかりません: {パス}」を表示 |
| URLアクセス失敗 | エラー: 「URLにアクセスできません: {URL}」を表示 |
| 機能が抽出できない | 警告: 「機能が見つかりませんでした。入力内容を確認してください」を表示 |
| タスク一覧ファイルが既存 | 確認: 「既存のタスク一覧を上書きしますか？」を表示 |

## 実行後の確認

- `docs/origami/tasks/task-list.md` が作成されたことを確認
- 生成されたタスク数を表示
- 信号別の件数サマリーを表示
- 次のステップ（run-task）を案内

## 関連コマンド

| コマンド | 説明 |
|---------|------|
| `/origami:run-task` | 生成されたタスクを個別に実行 |
| `/origami:verify-tasks` | タスクの完了状況を確認 |
| `/origami:extract-features` | 機能一覧を抽出（plan-tasks内で呼び出される） |
